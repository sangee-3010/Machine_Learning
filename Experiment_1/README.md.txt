# 🤖 Machine Learning Laboratory

A collection of Machine Learning laboratory experiments implemented using **Python**, **NumPy**, **Pandas**, **SciPy**, **Scikit-learn**, and **Matplotlib** as part of the **ICS1512 – Machine Learning Algorithms Laboratory** course.

## 📌 About

This repository contains implementations of supervised and unsupervised machine learning algorithms, data preprocessing techniques, ensemble methods, visualization, and model evaluation experiments.

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/sangee-3010/Machine_Learning.git
```

2. Navigate into the project

```bash
cd Machine_Learning
```

3. Install the required libraries

```bash
pip install numpy pandas scipy matplotlib scikit-learn jupyter
```

4. Open the notebooks

```bash
jupyter notebook
```
